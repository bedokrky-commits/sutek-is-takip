# SUTEK İş Takip – Windows Masaüstü Uygulaması v2.5

Bu klasör Electron tabanlı Windows masaüstü uygulamasını üretir.

## Otomatik EXE oluşturma
Dosyaları GitHub deposuna yükledikten sonra:

1. GitHub > Actions
2. "Build SUTEK Windows Desktop"
3. En son çalışmayı açın.
4. Alt bölümdeki `SUTEK-Is-Takip-Windows-Setup` artifact'ını indirin.
5. ZIP içindeki `SUTEK-Is-Takip-Setup-2.5.0.exe` dosyasını çalıştırın.

İlk açılışta canlı SUTEK İş Takip web adresi sorulur.
Adres bir kez kaydedildikten sonra program sonraki açılışlarda doğrudan uygulamayı açar.
